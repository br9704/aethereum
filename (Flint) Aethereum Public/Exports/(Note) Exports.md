# Exports

**Anything tagged `#export` lands here.** Currently empty.

## What `#export` means

Tag a note `#export` when its content is meant to leave this vault. `flint` collects tagged notes here, so "what is ready to publish" is a query rather than a memory.

## The unusual thing about this project

**For most vaults, `Exports/` is where content leaves for the outside world. Here the outside world is a five-file repo, and this vault is bigger than it.**

So there is exactly one realistic export, and it is a patch rather than an essay:

**A corrected `MCP.md`.** Four tools added (`await_team_events`, `get_contract_history`, `depend_on`, `set_ruleset`), two marked deprecated (`clear_directive`, `blast_radius`), a short resources section, and the editor list reconciled with `README.md`. The full specification of that change is already written in [[(Note) Drift Against 0.9.9]].

When that patch is drafted, it belongs here tagged `#export`, destined for `br9704/aethereum` as a third commit.

## Not to be confused with

**"Exports" in the product sense.** Aethereum's MCP tools export nothing to this folder. This is vault plumbing.
